# 总纲清单（可复制）

## 总纲定位
- 这个系统的终局不是单一策略脚本，而是一个资管财富系统。
- 核心不是追求单策略最优，而是控制下牌桌概率、确保赢钱能够被收割回到安全资金层。
- 系统应当以三账本组织资金：
  - Treasury
  - Growth
  - Gamble

## 资金宪法
- Treasury 不能反向救赌。
- Gamble 可以归零，但赢钱必须 Harvest，回灌安全资金。
- 任何策略都必须服从统一的风险闸门和预算约束。

## 组织与流程
- 中央银行式治理不是装饰，而是整个风控、现金流、权限和预算系统的核心。
- 一期可以先落地趋势与鲨鱼策略，但必须按终局主设计演化。
- AI 应先通过高质量问题理解项目，再逐步补读实现，不允许直接把愿景文档当最终答案。
