# 正式总流程 v2

## 一、主运行流程

### 启动与基线

0. 启动 orchestrator，加载配置、状态、skill 注册表。
1. 读取 `project_config.json`。
2. 校验技能、文档、schemas、仓库、state 环境是否可用。
3. 恢复或创建 learning baseline thread。
4. 用 `$learn-baseline` 初始化或刷新项目知识。
5. 恢复或创建 run baseline thread。

### 需求澄清与取证

6. 接收原始需求 `raw_request`。
7. 进入 coach 澄清回合。
8. 输出 `clarified_job_v1 + claims`。
9. 进入 verification coordinator。
10. 收集 `evidence_pack`。
11. project-coach 二次修正，输出 `clarified_job_v2`。

### 需求博弈与任务规划

12. 进入需求博弈/校正环节。
13. 输出 `corrected_job`。
14. run baseline 拆出 `task_plan`。

### 角色执行与质量治理

15. orchestrator fork dev / test / arch 等角色线程。
16. 子线程执行。
17. 回收当前有效结果集（active results）。
18. 进入 defect triage。
19. 根据 triage 结果分流：

* repair loop
* replan loop
* discussion round
* 或直接进入 merge

### 汇总与学习回流

20. run baseline 去噪汇总。
21. 汇总结果回流 learning baseline。
22. 更新 registry / state / evidence / claim 状态。

## 三、运行保障机制

这些不是“附加功能”，而是正式运行的一部分。

### 1. active result set

系统只消费“当前有效结果”，不把旧 test fail 和新 re-check 结果混在一起。

### 2. cycle limits

系统对以下回路设上限：

* repair cycle
* replan cycle
* discussion cycle

超限后进入阻断态，避免无限自转。

### 3. defect status

系统统一维护缺陷流转状态，例如：

* `DEFECT_REPAIRING`
* `DEFECT_REPLANNING`
* `DEFECT_DISCUSSING`
* `DEFECT_BLOCKED`
* `READY_TO_MERGE`

### 4. events

每一步关键决策都会落事件审计日志。

### 5. checkpoints

每个关键阶段都会落 checkpoint，支持回看和恢复。

### 6. resume / recover

系统支持：

* `resume_job(job_id)`
* `resume_latest_incomplete_job()`

可以从中间阶段继续，而不是每次从头开始。

## 四、验证与发布流程

这些不是单次 job 主流程的一部分，但属于实验线正式配套能力。

### 1. smoke suite

用于开发级一键回归验证。
入口：

```text
python3 tests/run_smoke_suite.py
```

### 2. gate

用于发布级统一验证门。
入口：

```text
python3 tests/run_gate.py
```

默认会执行：

* `py_compile`
* `smoke_suite`
* `integration_real_app`（默认 SKIPPED，只有显式开启才运行）

### 3. integration real app smoke

用于最小真实 app-server 契约验证。
默认跳过，只有设置环境变量才运行。

## 五、项目接入流程

这部分属于“基座如何接入第二个项目”。

### 1. skeleton mode

只生成最小目录和文档骨架。

### 2. runnable mode

生成最小可运行接入骨架，包括：

* 最小 core skills registry
* `.agents/skills/`
* `docs/NEXT_STEPS.md`

### 3. runtime-bundle mode

在 runnable 基础上进一步带上最小 runtime bundle，使目标项目具备本地自验证能力。

### 4. bootstrap 入口

统一入口：

```text
python3 scripts/bootstrap_experiment_project.py <target_path>
```

可选：

* `--with-core-skills`
* `--with-runtime-bundle`
